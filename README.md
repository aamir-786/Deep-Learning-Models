# 🧠 Deep Learning Models

This repository contains a collection of deep learning models built using **Python**, **TensorFlow**, and **Keras**.  
Each notebook demonstrates core concepts like model building, training, evaluation, and dataset handling.

---

## 📁 Contents

- **DL_Assignment_03_CNN.ipynb** – Basic CNN implementation and workflow  
- **MNIST_Fashion.ipynb** – Image classification using the Fashion MNIST dataset  
- **Plant_Classification.ipynb** – Plant leaf classification using CNNs  
- **update_readme.py** – Script to automatically update this README  
- **.github/workflows/** – GitHub Actions for CI/CD automation
